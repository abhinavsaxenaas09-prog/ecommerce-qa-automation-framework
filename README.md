# E-Commerce QA Automation Framework

A personal, non-confidential demo project showing enterprise-style UI and API automation framework design.

## Tech Stack
- Java
- Selenium WebDriver
- TestNG
- Page Object Model
- Maven
- RestAssured
- GitHub Actions
- Extent-style reporting structure

## Framework Features
- Driver factory
- Base test setup
- Page Object Model
- Explicit wait utility
- Configuration management
- TestNG listener
- Screenshot-on-failure hook
- Retry analyzer
- UI and API test examples
- Smoke and regression suite grouping
- CI/CD workflow

## Important Note
This is a personal demonstration project. It contains no client source code, client URLs, credentials, screenshots, or confidential information.

## Suggested Interview Explanation
"I created this personal framework to demonstrate how I would structure a maintainable UI and API automation solution. The repository separates driver management, page objects, API utilities, listeners, test data, and test execution configuration."
